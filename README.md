# 小型图书馆管理系统

面向小型图书馆（社区/学校/科室资料室）的轻量级图书借还管理系统。围绕「图书 → 读者 → 借出 → 归还」闭环，提供最必要的管理能力，界面简洁、单机即可部署。

## 功能

- **概览看板**：书目种类（按分类去重统计）、藏书册数、读者人数、在借册数、逾期未还数量，并列出最近逾期的 5 条记录；每个统计卡片都可点击，直接跳到对应的图书、读者或借阅列表。
- **图书管理**：新增/编辑/删除图书，记录 ISBN、作者、分类、出版社、馆藏位置与总册数；可借册数随借还自动变化；支持按书名/作者/ISBN 搜索、按分类标签筛选（搜索栏下方的标签，显示每个分类的图书数量，可与关键词叠加）、分页与输入页码跳转。
- **图书简介与封面**：图书详情页展示一句话简介和封面（没有封面时按书名首字生成占位图）；新增/编辑图书时可以填写简介并上传封面图片（PNG/JPG/GIF/WEBP，最大 2 MB），也可一键移除已有封面；列表中的书名前会显示封面缩略图。
- **读者管理**：登记/编辑/删除读者，记录借书证号（唯一）、姓名、性别、电话、邮箱、状态（正常/停用）与可借上限；有逾期未还图书的读者，状态会显示为「逾期」并禁止继续借书；列表直接显示每个人「在借 / 上限」；支持按证号/姓名/电话/邮箱搜索与分页。
- **借还管理**：选择读者与图书办理借出，按状态（全部/在借/逾期/已归还）筛选，一键还书；借阅列表显示每条记录的「剩余 / 逾期」天数（在借显示「剩 N 天」、到期当天显示「今天到期」、逾期显示「逾期 N 天」、已归还显示「—」），自动计算应还时间与逾期天数。
- **图书/读者详情**：从列表点进详情页，查看图书的在借读者与借阅历史、读者的在借图书与剩余可借额度；详情页可直接还书，或带着当前图书/读者跳到借书页，借还列表中的书名与读者名也可互相跳转。
- **借阅规则**：可借册数大于 0、读者状态正常、读者没有逾期未还的图书、单人在借数不超过其可借上限（默认 5 册）、同一本书未归还时不能重复借阅、借期默认 30 天。
- **数据保护**：存在未归还借阅的图书/读者不能删除；存在历史借阅记录时也不能删除（读者可改为「停用」，图书可保留归档），以保证借阅历史可追溯。
- **示例数据**：首次启动时自动导入 40 本常见图书（文学、历史、计算机、科普等分类，并自带简介），以及 8 位示例读者（含性别、电话、邮箱）与 20 条借阅记录（12 条已归还、5 条在借、3 条逾期），可直接体验搜索、分类筛选、分页与借还流程。导入只执行一次：已有图书按 ISBN 去重、不会被覆盖，缺失的示例书会补齐；示例读者按借书证号去重；示例借阅记录只挂在示例读者名下；之后删除示例数据也不会被加回来。对于早期导入、还没有简介的示例图书，启动时会按 ISBN 自动补全简介（不会覆盖自己填写的内容）。从旧版升级时，会先清理旧版示例读者（证号 R-2026-001 ~ R-2026-006）及其借阅记录，并把占用的库存归还，再写入新版示例数据。
- **界面**：统一表单控件尺寸与聚焦样式，登录页独立卡片式设计；布局宽度自适应浏览器窗口，页脚始终贴底；列表悬停高亮，窄屏下表格可横向滚动。

## 技术栈

| 层次 | 选择 |
| --- | --- |
| 语言 | Java 21 |
| 框架 | Spring Boot 3.5.16（Web / Data JPA / Security / Validation） |
| 视图 | Thymeleaf 服务端渲染 + 原生 CSS |
| 数据库 | SQLite（文件库，免安装） |
| 测试 | JUnit 5 + Spring Boot Test + MockMvc + AssertJ |

## 快速开始

前置条件：JDK 21、Maven 3.9+。

```bash
# 启动（默认端口 8080，数据库文件为 data/library.db）
mvn spring-boot:run
```

浏览器打开 <http://localhost:8080>。

首次启动会自动创建管理员账号：

- 用户名：`admin`
- 密码：`admin123`（生产使用请通过配置项 `library.admin.password` 修改后再初始化数据库）

登录后即可在「图书」「读者」「借还」三个页面完成日常操作。

## 配置

配置位于 `src/main/resources/application.yml`：

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `server.port` | 服务端口 | `8080` |
| `library.version` | 页面页脚显示的版本号（与 `pom.xml` 保持一致） | `0.8.0` |
| `spring.datasource.url` | SQLite 数据库地址 | `jdbc:sqlite:data/library.db?...` |
| `library.loan.period-days` | 借期（天） | `30` |
| `library.admin.username` | 初始管理员用户名 | `admin` |
| `library.admin.password` | 初始管理员密码 | `admin123` |
| `library.seed.books` | 首次启动时是否导入 40 本示例图书（只执行一次） | `true` |
| `library.seed.demo-loans` | 首次启动时是否导入示例读者与借阅记录（含逾期） | `true` |
| `library.cover-dir` | 图书封面的本地保存目录（页面通过 `/covers/**` 访问） | `data/covers` |
| `spring.servlet.multipart.max-file-size` | 单个上传文件大小上限 | `2MB` |

数据文件位于工作目录下的 `data/library.db`（已被 `.gitignore` 忽略），备份该文件即备份全部数据；封面图片位于 `data/covers/`。

## 测试

```bash
mvn test
```

测试覆盖：

- `BookServiceTest`：图书新增/修改/删除规则、库存重算、搜索与分页。
- `ReaderServiceTest`：读者登记、证号唯一性、邮箱与性别保存与搜索、停用后不可借、删除保护、搜索。
- `LoanServiceTest`：借书规则（无库存/停用/超上限/重复借阅/逾期未还）、还书与库存恢复、逾期天数、剩余天数、状态筛选、按图书/读者维度的在借与历史查询、历史分页。
- `WebFlowTest`：登录鉴权、表单校验（含邮箱格式）、端到端闭环（新增图书 → 登记读者 → 借出 → 还书）、业务错误提示、详情页展示与还书后回到详情页、图书列表分页、按分类标签筛选（含与关键词叠加、分类数量、空分类提示）、页码跳转与越界钳制、概览分类数与卡片跳转、逾期读者状态展示与被拒绝借书、借书表单禁用逾期读者、读者列表的邮箱/性别/在借数量、借阅列表与读者详情的剩余/逾期天数。
- `DemoBooksTest` / `BookSeederTest` / `DataInitializerTest`：示例书目的完整性与唯一性、首次启动只导入一次并写入标记、已有图书按 ISBN 保留且补齐缺失、清空后不再重复导入、初始化时按开关决定是否导入。
- `DemoLoanSeederTest`：新版示例读者（邮箱/性别）与 20 条借阅记录的生成数量、逾期/已归还/在借分布、可借数扣减一致性、旧版示例读者与借阅的清理与库存归还、一次性标记与无可用图书时的降级。
- `CoverStorageTest`：封面保存与访问路径、文件落盘、空文件、非图片类型、超过 2 MB 的拒绝、非法路径删除保护。
- `BookSeeder` 相关测试同时覆盖「已有图书简介自动补全」。

## 目录结构

```
src/main/java/com/example/library
├── config/        # 安全配置、初始化管理员与示例图书
├── domain/        # 实体：Book、Reader、Loan、UserAccount 及枚举
├── repository/    # Spring Data JPA 仓储
├── service/       # 业务逻辑与 BusinessException
└── web/           # Controller 与全局异常处理
src/main/resources
├── templates/     # Thymeleaf 页面（books/readers/loans/login/index/error）
├── static/css/    # 样式
└── application.yml
src/test/java/com/example/library
├── config/        # 示例数据与初始化测试
├── service/       # 业务层测试
└── web/           # Web 层端到端测试
```
